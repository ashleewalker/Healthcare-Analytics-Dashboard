# CareSight Healthcare Analytics Dashboard

A self-contained React + Vite dashboard for exploring hospital operational and patient-performance metrics.

## Stack

- React 19
- Vite 7
- Lucide React
- Vitest
- npm
- Node.js 20

## Features

- Hospital KPI cards
- Admissions/discharges trend visualization
- Department utilization tracking
- Searchable patient table
- Responsive navigation
- Dark mode
- No external API or credentials required

## Run

```bash
nvm use 20
npm install
npm run dev
```

## Tests

```bash
npm test
```

The test suite uses only deterministic local utility functions and does not require network access, secrets, or external services.
